# 🛡️ Social Engineering Awareness Platform

A defensive cybersecurity awareness platform built with Python and Streamlit.

The project teaches users how to recognize and safely respond to common
social-engineering techniques through simulated scenarios and an interactive
security-awareness assessment.

---

## 🎯 Project Purpose

Social engineering attacks target people through deception and manipulation.

Attackers may attempt to convince users to:

- Reveal passwords
- Share OTPs or MFA codes
- Open malicious links
- Download suspicious attachments
- Transfer money
- Bypass physical security controls

This project focuses on defensive awareness and safe decision-making.

---

## ✨ Features

- 🎣 Phishing awareness
- 📱 Smishing awareness
